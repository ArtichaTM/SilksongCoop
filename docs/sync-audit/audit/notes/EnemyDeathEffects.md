# EnemyDeathEffects [note by main 2026-10-25]
Pre-instantiates the corpse (and alt corpses) as an inactive child of the enemy when the room loads. On death EmitCorpse reparents it to the scene root (or to the PersistentFolderReset parent) and activates it; recyclable corpses come from the object pool instead. Corpse spawn position and z use UnityEngine.Random.
Coop: after death the corpse is no longer under the enemy, so it no longer counts as part of the enemy, and its hierarchy position differs per game. Each game flings its own corpse (fling uses the hit direction, a random angle and the enemy position at death), so corpses land in different spots; a creature released at the corpse (PreInstantiateGameObject) then appears at different places. Run such corpses in one game and place the other game's corpse at that game's landing spot.
