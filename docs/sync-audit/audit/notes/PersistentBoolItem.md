# PersistentBoolItem / PersistentIntItem [note by agent 2.03]
Per-object saved flag: reads SceneData on Start (OnSetSaveState / FSM var "Activated"), writes it back only when GameManager.SavePersistentObjects fires (scene exit, bench, save) - not at the moment of change.
Coop: a flag flipped in one game reaches the other only as saved scene data, applied on its next load of that room; the live object never changes. A live effect needs the triggering event shared.
Live state and arrival [main 2026-10-25]: A saved object keeps its live state on itself (OnGetSaveState, or an FSM bool) and writes it into SceneData only when GameManager raises SavePersistentObjects (leaving the room, saving, SaveLevelState). On Start it reads SceneData and calls OnSetSaveState, which shows the finished result without effects (rosary string beads gone, cocoon broken, platform down). Coop: a player who enters a room the other is still in loads the SceneData from before that player's changes in the room; the live values have to be handed over on arrival.
