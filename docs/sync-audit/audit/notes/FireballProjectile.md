# FireballProjectile [note by agent 2.03]
Bouncing lava/fire rock (used by DF Lava Rock inside barrels): has DamageHero, bounces off terrain for a few hops, breaks on lava, on hero contact (ExplosionRock) or when hit by a weapon, then explodes with an antic.
Damages whoever is the local hero in that game; pure projectile, no PlayerData. Spawned by a breakable, so each game spawns its own.
