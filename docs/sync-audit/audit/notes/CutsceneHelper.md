# CutsceneHelper [note by agent 2.19]
Skippable cutscene/credits router: on skip or LoadNextScene loads the next scene by type: named scene, End_Game_Completion, End_Credits, permadeath unlock, boss return (PD bossReturnEntryGate), or ReturnToMainMenu with or without save.
Touches: input skip mode, scene loads, return to menu (ends the play session for that game).
