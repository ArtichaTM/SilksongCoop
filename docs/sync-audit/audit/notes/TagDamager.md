# TagDamager / TagDamageTaker / CustomTag [note by agent 2.15]
TagDamager (e.g. barnacle "Dust Damager") adds a damage-over-time tag to any HealthManager with a TagDamageTaker that stays in its trigger; removed on exit or disable. CustomTag marks projectiles/objects (Bomb, DustBomb, LightningBola, SkinnyMosquito, CogworkHatchling) that a Swamp Barnacle tendril may grab and eat; IsSuckable() true for the first four.
Touches enemy HP only, no PlayerData.
