# TrackingTrail [note by agent 2.03]
Spline of silhouettes that fades up and down along a path to show a scent trail (Rock Roller tracking). Driven by event-register messages (TRAILS END/OFF) from the Rock Roller Dung / RockDebris interactions and can continue into the next scene.
Visual only; the gameplay is the interactable that locks the hero and the quest state it checks.
